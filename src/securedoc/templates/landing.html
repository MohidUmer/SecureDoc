Secure collaboration

Store, share, and discuss documents — encrypted at rest.

SecureDoc is a prototype for authenticated access, role-based sharing (view, comment, edit), version history, and an admin audit trail. File payloads are encrypted on the server before they are written to disk.

What you can do

Designed around common secure-document workflows.

Encryption at rest

Uploads are protected with a server-side Fernet key. Ciphertext lives under a dedicated folder; the database stores metadata and access rules — not your file contents.

Get started →

Share with roles

Invite collaborators by username: view (read/download), comment, or edit (including new versions). Only the owner can share or delete.

Get started →

Audit & accountability

Security-relevant actions are logged: sign-in outcomes, uploads, downloads, sharing changes — without storing passwords or file bodies in the log.
